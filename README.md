# Motion-Sensor-Lamp
The project combines an Arduino Nano, an HC-SR04 ultrasonic sensor, and a warm-white LED lighting system to create a compact and minimalist lighting solution. The enclosure is designed in Autodesk Fusion 360, with dedicated spaces for electronic components, sensor openings, mounting posts, and a light diffuser.
